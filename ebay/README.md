# RentADriver for eBay

eBay connector on the **shared commerce layer**, planned as a **fulfillment connector** rather than a checkout plugin:
eBay has no live-rate hook, no "same-day" shipping service, no tracking-link field and no app directory. The seller
offers a flat-priced local courier option (`Same-day by RentADriver`, service `UK_OtherCourier24` / `ShippingMethodOvernight`,
carrier `Other`, handling time 0); RentADriver takes the orders that chose it (push notification + 2-minute poll),
prices each one before booking (no postcode targeting on eBay, so out-of-area orders go to *Needs action*), books a
driver, writes the tracking number back with `createShippingFulfillment`, and texts the buyer the live tracking link.

Scope: US sellers and **UK business sellers** (UK private sellers must use eBay Simple Delivery since April 2025).

|---|---|

## Marketplace Account Deletion endpoint

eBay pushes a notification when a user asks for their data to be deleted; every application must subscribe (or file an
exemption) before its first production call. Protocol and portal steps: developer.ebay.com → Marketplace User Account
Deletion guide (checked 2026-10-01).

| | |
|---|---|
| URL | `GET`/`POST https://api.rentadriver.ai/v1/ebay/account-deletion` — must match the URL saved in the portal byte for byte |
| Challenge | `GET ?challenge_code=…` → `{"challengeResponse": hex(sha256(code + token + endpointURL))}`; 503 until the verification token is configured |
| Verification token | 32–80 chars of `[A-Za-z0-9_-]`, generated by us, saved in the portal (Application Keys → Notifications → Marketplace Account Deletion) and in the API environment |
| Notification | `POST` → always 200 (`accepted` when the `X-EBAY-SIGNATURE` ECDSA signature verifies against `getPublicKey(kid)`, `unverified` otherwise); only verified notifications are acted on. Verification needs the app keyset (sandbox or production) |
| Action | P0: logged. P1: the shared customer-redaction path, keyed on the eBay `userId` |
| Alert e-mail (portal) | `<your alerts address>` — eBay mails it when the endpoint stops acknowledging |

Portal order: save the alert e-mail → save the endpoint URL + token (eBay sends the challenge at once; the token must
already be live in the API) → **Send Test Notification** → expect `{"received":true,"result":"accepted"}` in the API log.

Production needs the verification token in the API environment (and later the keyset).
